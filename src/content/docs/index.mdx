<p class="hg-lede">
  Every harness-evolution method reports a score delta. None can say what it is
  <strong>made of</strong>. HarnessGrad measures every candidate itself — same tasks, same
  scorer — so their curves land on one axis.
</p>

<p class="hg-caption">The local demo, end to end. 4 tasks, no network, no cost.</p>

<div class="hg-grid">
  <div class="hg-cell">
    <span class="hg-num">01</span>
    <h3>Scoring is not delegable</h3>
    <p>A subject that scores itself makes every comparison meaningless.</p>
  </div>
  <div class="hg-cell">
    <span class="hg-num">02</span>
    <h3>Methods live outside</h3>
    <p>A method returns candidate harnesses. The platform measures those.</p>
  </div>
  <div class="hg-cell">
    <span class="hg-num">03</span>
    <h3>Isolation is recorded</h3>
    <p>Runs made under different rules never share an axis.</p>
  </div>
</div>

```bash
./install.sh --check        # verify the host; changes nothing

export HG_AGENT_BACKEND=mock
python3 driver.py --dataset demo --sampling all --harness loop --rounds 2 \
    --run-id control --method-entrypoint "python $PWD/methods/noop/run.py"
```
